# Milestone 5 evidence

Summaries, charts, per-run `report.md` files, screenshots and small state JSON
stay in git. The bulky raw data (per-frame `frames.csv`, large `result.json` /
lifecycle JSON and full-resolution matched PNG captures, ~1.4 GB) was moved out
of git history on 2026-11-15 to keep the repository cloneable.

Download it from the [evidence-milestone5 release](https://github.com/stephenfjohnson/beamng-scratches-mod/releases/tag/evidence-milestone5):
`scratches_mod-milestone5-raw-evidence.zip` holds this whole folder as it was
before the rewrite (old commit `56ba091`, kept in a local backup bundle), with
repo-relative paths. Extract it at the repository root to restore
every file the investigations reference.
